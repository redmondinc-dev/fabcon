# FabCon Europe 2026 debrief

A short, public website that reports what one attendee learned at FabCon Europe 2026 (Barcelona) about applied AI, security and governance in Microsoft Fabric.

- **Main message:** An agent needs context, limits and proof.
- **Scope:** one attendee, one focus. This is not a report of the full conference.
- **Evidence:** each statement is from a speaker, from Microsoft or from a third party, and is labelled. Nothing here was tested in our own tenant.
- **Credit:** ideas belong to the speakers named in `content/sources.json`. Slide images are not published.

## Layout

| Path | Content |
|---|---|
| `plan/` | Site specification, style guide, page outlines |
| `content/claims.json` | Claims register |
| `content/sources.json` | Bibliography |
| `content/pages/` | Page content in Markdown (to be written) |
| `private/` | Local source material. Git-ignored. Not part of this repository. |

Status values such as "preview" and "generally available" are correct as of 1 October 2026.
