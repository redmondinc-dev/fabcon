# FabCon Europe 2026: AI, security and governance

A short, public website that reports what we learned at FabCon Europe 2026 (Barcelona) about applied AI, security and governance in Microsoft Fabric.

- **Main message:** Fabric gives agents context. Control and proof are a work in progress.
- **Scope:** one main focus. Two of us attended: one with a focus on applied AI, and a data engineer. This is not a report of the full conference.
- **Evidence:** each statement is from a speaker, from Microsoft or from a third party, and is labelled. Nothing here was tested in our own tenant.
- **Credit:** ideas belong to the speakers named in `content/sources.json`. Slide images are not published.
